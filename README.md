# newPenguinAgreement
The first task is Android Studio (Kotlin)

## Task:
Create one screen
 
## A minimum of elements on the screen:
* Four text fields for entering information:
1.   Numeric
2.  Numeric
3.   Text
4.   Text
* Text view, where the information from the fields above is put into a template (text) and displayed on the screen.
 
## Also implement:
* Text remains formatted regardless of device orientation (screen rotation)
* When exiting the application the information entered earlier is saved
* Numeric fields are checking for input, if the information is not entered or entered incorrectly, a message appears that you must enter the correct information
* Next to the numeric field should be a noun that must be paired with this numeral
 
## Checklist:
* The code is written in Kotlin
* The application has no runtime errors
* When you turn the screen, the entered information is not reset
* The interface should be as intuitive as possible, so it is clear to the user what, where and why to enter
* With any entered/displayed data, all information should be visible, fields should not overlap each other, if necessary, scrolling should appear
